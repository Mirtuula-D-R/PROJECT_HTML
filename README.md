# Basic HTML Website

This project is a simple **multi-page HTML-only website** created to practice web development fundamentals.  
It focuses on semantic structure, navigation, and SEO meta tags without any CSS styling.

---

## 📌 Pages Included
- **Homepage (index.html)** – Introduction and welcome message.
- **Projects (projects.html)** – Showcases sample projects.
- **Articles (articles.html)** – Contains blog-style articles.
- **Contact (contact.html)** – Includes a contact form with fields for name, email, and message.

---

## 🧩 Features
- **Navigation bar** present on all pages for easy access.
- **Semantic HTML structure** using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **SEO meta tags** (`description`, `keywords`, `author`) included in each page.
- **Contact form** with required fields for user input.

---

## 🎯 Learning Goals
- Understand how to create **multiple pages** in a website.
- Learn to structure a site **semantically** with HTML.
- Prepare a clean structure that can be **styled later with CSS**.
- Practice adding **basic SEO meta tags** for better discoverability.

---
